# 04 AI 使用与个人贡献记录

## 已实际发生的 AI 辅助

候选人向 Codex 提供考核题、选择 DeepSeek，并提供本机模型配置位置/截图信息。
Codex 协助需求拆解、架构选择、代码、测试、合成数据、文档撰写、命令执行和问题修复。
本仓库当前实现主要由 AI 辅助生成，不能将全部代码、文档或自动测试声称为候选人独立完成。
候选人对系统的实际理解、手动修改和独立复测目前尚未有可核验证据，不虚构个人贡献。

业务运行阶段的真实 Agent 模型是 DeepSeek `deepseek-flash`，负责根据工具观察选择动作。
离线 `Mock` 是 AI 编写的确定性代码，不是另一个真实模型，不用于证明真实决策能力。

## 已执行验证

在 Anaconda `guohaiyu` 中运行单元测试与离线场景，再使用本机私密配置请求官方 DeepSeek 接口，记录真实工具调用。
发生的测试连接清理失败和修复过程见评估与复盘文档。
提交的实际输出文件由评估脚本生成，不以预设决策日志代替真实模型 Trace。

## 隐私与记录范围

模型凭据只在内存中读取，不写入项目文件、运行输出或示例；本地配置由 `.gitignore` 排除。
提交合成素材、工具参数、结果摘要及短 `reason`，不采集模型内部思维过程。
外部文档查询使用公开 API 协议，未向文档工具提交密钥。

按实际情况补充：本人阅读并理解的模块、本人修改的文件与原因、本人执行的复测命令和结果、真实投入时间。
